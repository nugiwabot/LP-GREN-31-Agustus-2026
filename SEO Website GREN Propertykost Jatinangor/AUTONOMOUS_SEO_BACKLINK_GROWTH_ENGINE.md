## 4. Rincian 6 Kriteria Evaluasi Biner (Quality Gates)

Setiap artikel sebelum dipublikasikan ke Medium, Blogger, atau Pinterest harus mendapatkan nilai **PASS (1)** pada 6 evaluasi berikut:

| No | Kode Eval | Pertanyaan Evaluasi | Kondisi Lolos (PASS) | Kondisi Gagal (FAIL) |
| :-: | :--- | :--- | :--- | :--- |
| **E1** | `CHECK_BACKLINK_URL` | Apakah artikel memiliki link aktif ke `gren.biz.id`? | Link berformat `https://www.gren.biz.id/...` ada dan URL tujuan valid. | Link hilang, salah ketik domain, atau link rusak. |
| **E2** | `CHECK_ANCHOR_TEXT` | Apakah anchor text backlink alami dan relevan? | Menggunakan anchor kata kunci alami (misal: *"analisis sewa kost"*, *"GREN Propertykost"*). | Anchor generik seperti *"klik disini"* atau over-optimized spam. |
| **E3** | `CHECK_UNIQUENESS` | Apakah konten bebas dari plagiarisme murni (*anti-slop*)? | >80% susunan kalimat berbeda dari artikel induk (gaya opini/studi kasus unik). | <80% kemiripan (copy-paste mentah yang memicu penalti Google). |
| **E4** | `CHECK_AEO_DATA` | Apakah artikel memuat fakta angka konkret? | Memuat angka spesifik (Yield 8%–12%, 100.000+ mahasiswa, Jatinangor, SHM). | Artikel hanya berisi opini umum tanpa data angka. |
| **E5** | `CHECK_WORD_COUNT` | Apakah panjang artikel pas untuk sindikasi? | Antara 400 s/d 800 kata (ringkas, padat, mudah dibaca cepat). | Terlalu pendek (<350 kata) atau bertele-tele (>1.200 kata). |
| **E6** | `CHECK_CTA_WHATSAPP` | Apakah ada ajakan aksi konsultasi ke WhatsApp resmi? | Mencantumkan nomor resmi `+6282246846950` atau link website. | Nomor kontak tidak ada atau menggunakan nomor lama. |

## 6. Panduan Integrasi API Key Gratisan

Semua API Key berikut diperoleh secara **100% Gratis** tanpa kartu kredit:

### A. Blogger API (Google Cloud) — Gratis Selamanya
1. Masuk ke [Google Cloud Console](https://console.cloud.google.com/).
2. Buat Project Baru: *"GREN Syndication"*.
3. Buka **APIs & Services** ➔ Cari **Blogger API v3** ➔ Klik **Enable**.
4. Buka **Credentials** ➔ Buat **API Key** & **OAuth Client ID**.
5. Salin `Blog ID` dari dashboard Blogger Anda (`risetpropertijatinangor.blogspot.com`).

### B. Medium Integration Token — Gratis (1 Menit Jadi)
1. Login ke [Medium.com](https://medium.com).
2. Masuk ke **Settings** ➔ **Security and Apps** ➔ scroll ke bawah ke **Integration tokens**.
3. Ketik deskripsi token (misal: *GREN Publisher*) ➔ Klik **Get integration token**.
4. Token ini dimasukkan ke konfigurasi skrip Python untuk posting otomatis.

### C. IndexNow API Key — Gratis & Instan
1. Buat berkas teks acak di root website: `indexnow_key.txt`.
2. Masukkan kode key unik tersebut ke skrip publisher untuk auto-ping ke Bing & Yandex setiap kali posting.

## 8. Risk Mitigation & Google Spam Prevention

Agar website selalu aman dan disukai oleh Google SpamBrain:

1. **Jeda Waktu Alami (*Drip Feeding*):**  
   * Jangan memposting 60 artikel sindikasi sekaligus dalam 1 jam.  
   * Skrip diprogram untuk menerbitkan 2–3 artikel per hari secara konsisten dan natural.
2. **Variasi Anchor Text (*Anchor Diversity*):**  
   * 40% Brand Anchor: *"GREN Propertykost"*, *"GREN Propertykost Jatinangor"*.
   * 35% Topic Anchor: *"analisis sewa kost mahasiswa"*, *"kalkulator rental yield UNPAD"*.
   * 25% URL Bersih: *"https://www.gren.biz.id"*.
3. **Canonical Reference:**  
   * Di Medium dan platform yang mendukung canonical tag, cantumkan sumber aslinya mengarah ke `https://www.gren.biz.id/artikel/...` untuk memperkuat sinyal otoritas.
